# Astra CPU Silencer Standard

**Windows標準の電源管理機能を活用した、静音・省電力・発熱対策のためのCPU電源管理ユーティリティ**

Astra CPU Silencerは、CPU電圧やBIOS設定を直接変更することなく、Windowsに備わっている電源管理機能を利用して、CPUの動作を調整するWindows向けユーティリティです。

複雑な設定をできるだけ分かりやすくし、日常的なPC利用での静音性、省電力性、発熱の抑制をサポートします。

## 💡 こんな方におすすめ

- ノートPCのファン音を抑えたい
- CPUの発熱を少しでも減らしたい
- バッテリー消費を抑えて使用したい
- 普段の作業ではCPUの性能を必要以上に使いたくない
- Windowsの電源管理設定を分かりやすい画面から操作したい

図書館やオフィス、自宅など、静かな環境でPCを使用したい方にもおすすめです。

## ⚙️ 主な機能

Astra CPU Silencerでは、以下の項目をGUIから管理できます。

- CPU最大周波数の上限設定
- CPU最小性能状態の調整
- CPUブースト動作の設定
- Windows電源プランの選択と切り替え
- AC（電源接続時）とDC（バッテリー駆動時）の個別設定
- 3種類の動作プリセット
- 変更前の設定への復元
- アプリ設定およびCPU電源設定の初期化

設定にはWindows標準の電源管理機能を利用し、CPU電圧を直接操作することや、BIOSを書き換えることは行いません。

※実際のCPU動作や設定の反映結果は、CPU、BIOS、Windows、PCメーカーの電源管理仕様などによって異なります。

## 🛡️ Standard版の設計

Standard版では、設定時の誤操作を抑えるため、入力範囲や設定適用の手順に制限を設けています。

### 最小周波数の入力制限

- 最小周波数の入力下限：1400MHz
- 設定単位：100MHz
- 最大周波数の「0MHz」は制限なしを意味します。

最小周波数に入力した値は、Windowsの「最小のプロセッサの状態（％）」に換算されます。

そのため、CPUの動作周波数を入力値に固定する機能ではありません。

また、オーバークロックを目的としたソフトウェアではありません。

## 🔍 CPU仕様データベース

Astra CPU Silencerは、独自のCPU仕様データベースを利用しています。

CPUメーカーと型番がデータベースの登録情報に完全一致した場合に限り、次の情報を表示します。

- メーカー公称ベース周波数
- メーカー公称最大周波数

データベースで確認済みの最大周波数を入力上限として使用し、未確認のCPUについて最大周波数を推測しません。

### 未登録CPUについて

CPU仕様データベースに該当情報がない場合は、最大周波数に「0MHz（制限なし）」を使用してください。

### 入力値の自動補正と二段階適用

確認済みの最大周波数を超える数値が入力された場合、入力欄の値を最大周波数へ自動補正します。

ただし、その操作だけではWindows側の設定を変更しません。

1. 入力値が自動補正される
2. ユーザーが補正後の値を確認する
3. ［設定を適用］を再度押すことで設定を反映する

この二段階方式により、意図しない数値がそのまま適用されることを防ぎます。

## 🛡️ 2500MHz入力時の自動補正

本プロジェクトの実機検証結果に基づき、2500MHzが入力された場合は2400MHzへ自動補正する仕様を採用しています。

これは本アプリ独自の入力補正処理であり、すべてのCPUで2500MHzの動作が危険であることを意味するものではありません。

## ⚡ 3つの動作プリセット

用途に合わせて、3種類のプリセットを用意しています。

| プリセット | AC（電源接続時） | DC（バッテリー駆動時） |
|---|---|---|
| 🔴 通常モード | 最大周波数制限なし | 最大周波数制限なし |
| 🟡 中速サイレント | 3.0GHz | 2.6GHz |
| 🟢 低速超省エネ | 1.8GHz | 1.6GHz |

タスクトレイからも簡単に切り替えられます。

※設定値はWindowsの電源管理に渡される値であり、実際のCPU周波数を常に指定値に固定するものではありません。

## 🔄 Windows電源プランの切り替え

Windowsに登録されている電源プランを、Astra CPU Silencerの画面から選択できます。

選択したプランは、そのままWindowsのアクティブな電源プランへ切り替えられます。

また、AC（電源接続時）とDC（バッテリー駆動時）の設定を個別に管理できます。

## 🔧 設定の復元と初期化

### 変更前へ復元

Astra CPU Silencerの使用前に保存したCPU電源設定、およびProcessorメニューの表示状態への復元を行います。

### 完全初期化

- CPU電源設定をAstra基準の初期値へ戻す
- ProcessorメニューをClean Baselineへ整理する
- アプリケーション設定を初期化する

※「完全初期化」はWindows全体やBIOSを初期化する機能ではありません。

## 🎁 60分間の無料体験

ライセンスを登録する前に、60分間の無料体験をご利用いただけます。

無料体験は累積時間方式です。

- 体験時間は合計60分間
- 手動で体験を終了した場合、残り時間は次回へ引き継がれます
- 体験時間の終了時には、保存された変更前のCPU設定への復元を試みます
- 復元処理の後、ライセンス登録画面を表示します

購入前に、お使いのPCで動作をご確認いただけます。
